## ⚠️ КРИТИЧЕСКИЕ ПРАВИЛА АРХИТЕКТУРЫ

1. **Primary Channel — 3D Звук.** Никаких текстовых полей для ребёнка. Голос (STT) и 3D-звук (TTS/Foley/Web Audio API).
2. **Визуал вторичен (Принцип Тёмной Комнаты).** Экран чёрный. Только Искорка (статус-орб).
3. **Zero Data (Автономный Форт).** Всё локально (IndexedDB + Service Worker). Ночной батч — обезличенная мета.
4. **LLM — только в Студии.** Искорка — книжка, а не чат-бот. Никакого `free_talk` в рантайме.
5. **Keyword-матчинг на устройстве ребёнка.** Только ключевые слова. Без LLM fallback.
6. **Матрица Эмпатии (Гиппенрейтер).** Никогда не давать готовых решений. Только вопросы.
7. **Одно касание — навсегда голос.** autoListen = true после первого тапа.
8. **Нет хард-стопа.** Есть честные последствия.
9. **Родитель — не полицейский, а ресурс для возвращения в светлую ветку.**
10. **Все мостики — доступны для слепых детей.** Запрещены задания, требующие зрения.
11. **Маяк = клиент Студии.** Генерация книг через Студию (18 агентов с ДНК, памятью, ревизией).

## 🎯 АРХИТЕКТУРНАЯ ПАРАДИГМА (v8.3)

### Принцип:
> **Студия генерирует. Маяк ретранслирует. Искорка играет. Родитель направляет.**

### 4 Слота Генерации (Студия):
- **Слот 1:** Герой (якорь навсегда) — из `characters_registry.json`
- **Слот 2:** Локация (атмосфера) — из `worlds_registry.json`
- **Слот 3:** Сюжет (скелет) — из `showcase/`
- **Слот 4:** Финал (артефакт + мостик) — из `finales_registry.json`

### Ключевые решения (v8.3):
- **Единый стандарт `STANDARD.md` v3.0** — объединяет и заменяет `BOOK_PACKAGE_SPEC.md` и `PROTOCOL.md`
- **`story_package.json`** — единый контрактный файл между Кабинетом, Маяком, Студией и Искоркой
- **Dual-format intake Студии** — принимает legacy BookRequest И story_package v3.0 от Маяка v7
- **biography_snapshot сквозной** — Маяк → API → state → hooks.py → A00 → chain_data → A16
- **A16 выдаёт story_package v3.0** — не файловый пакет, а контрактный JSON для Маяка
- **Deliver callback** — после генерации Студия сама шлёт главу на `POST /api/package/deliver`
- **keyword_map (A01)** — Нейро Спарк строит словарь ключевых слов для голосового управления Искорки
- **memory_vector → biography.json (A02)** — Хронос Мемо описывает карту памяти и правила эволюции
- **Персонаж-якорь** — выбирается один раз в первой книге и идёт через все главы
- **Первая книга — готовый пакет** — копируется из `ready_books/` при регистрации
