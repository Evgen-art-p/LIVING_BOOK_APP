## ⚠️ КРИТИЧЕСКИЕ ПРАВИЛА АРХИТЕКТУРЫ

1. **Primary Channel — 3D Звук.** Никаких текстовых полей для ребёнка. Голос (STT) и 3D-звук (TTS/Foley/Web Audio API).
2. **Визуал вторичен (Принцип Тёмной Комнаты).** Экран чёрный. Только Искорка (статус-орб).
3. **Zero Data (Автономный Форт).** Всё локально (IndexedDB + Service Worker). Ночной батч — обезличенная мета.
4. **LLM — высокоточный станок, а не фантазёр.** Только в Студии. 4 Слота. Чистые Реестры.
5. **Гибридный Мозг на устройстве ребёнка:** Keyword-матчинг (бесплатно) → LLM fallback через Маяк (кэш 80%).
6. **Матрица Эмпатии (Гиппенрейтер).** Никогда не давать готовых решений. Только вопросы.
7. **Одно касание — навсегда голос.** autoListen = true после первого тапа.
8. **Нет хард-стопа.** Есть честные последствия.
9. **Родитель — не полицейский, а ресурс для возвращения в светлую ветку.**
10. **Все мостики — доступны для слепых детей.** Запрещены задания, требующие зрения.
11. **Маяк = клиент Студии.** Генерация книг через Студию (18 агентов с ДНК, памятью, ревизией). Дублей нет.

## 🎯 АРХИТЕКТУРНАЯ ПАРАДИГМА (v8.1)

### Принцип:
> **Студия генерирует. Маяк ретранслирует. Искорка играет. Родитель направляет.**

### 4 Слота Генерации (Студия):
- **Слот 1:** Герой (якорь) — из `characters_registry.json`
- **Слот 2:** Локация (атмосфера) — из `worlds_registry.json`
- **Слот 3:** Сюжет (скелет) — из `showcase/`
- **Слот 4:** Награда (артефакт + 3D-звук) — из `artifacts_registry.json`

### Ключевые решения:
- **Чистые Реестры:** `system_registry/` отдельно от `books/personal/`
- **Картриджная Студия:** 11 цехов-картриджей, каждый с manifest.json + hooks.py
- **Headless API:** `api_living_book.py` — генерация без браузера, через CartridgeRunner
- **Историческая Память:** `biography.json` — ребёнок общается с другом, который помнит всё
- **Артефакты:** материальные награды с **3D-звуковыми петлями**, навсегда в коллекции
- **Доступность:** 100% мостиков в реальность не требуют зрения
