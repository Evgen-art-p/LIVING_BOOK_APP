# Living Book — Приложение (Плеер)

## Что это?

Приложение, которое ребёнок (и родитель) использует.
Оно загружает "книжку" (Book Package), созданную на конвейере студии,
и позволяет ребёнку прожить историю — слышать персонажей, разговаривать
с ними, делать выборы.

## Как это работает?

```
┌─────────────────────────────────────────────┐
│            СТУДИЯ (фабрика)                 │
│  16 агентов → создают Book Package          │
└──────────────────┬──────────────────────────┘
                   │ .zip / .json пакет
                   ▼
┌─────────────────────────────────────────────┐
│         ПРИЛОЖЕНИЕ (плеер)                  │
│                                             │
│  1. Загружает книжку                        │
│  2. Озвучивает сцену (TTS + 3D-звук)       │
│  3. Слушает ребёнка (микрофон → текст)      │
│  4. Думает через Gemini (ИИ-мозг)           │
│  5. Переходит к следующей сцене             │
│  6. Запоминает всё                          │
│                                             │
│  Родитель видит:                            │
│  - Что ребёнок выбирал                      │
│  - Как долго играл                          │
│  - С кем разговаривал                       │
│  - Может "вписать" реальную тему в историю  │
└─────────────────────────────────────────────┘
```

## Структура приложения

```
APP/
├── BOOK_PACKAGE_SPEC.md       ← формат пакета (контракт студия ↔ плеер)
├── ROADMAP.md                 ← план разработки по шагам
├── server/                    ← бэкенд (Python/FastAPI)
│   ├── main.py                ← точка входа
│   ├── story_engine.py        ← мозг: загрузка книжки, навигация по сценам
│   ├── ai_brain.py            ← подключение Gemini (свободный разговор)
│   ├── memory.py              ← память ребёнка (что выбирал, прогресс)
│   └── parent_api.py          ← API для родительского кабинета
├── player/                    ← фронтенд (то что видит/слышит ребёнок)
│   └── index.html             ← главная страница
├── dashboard/                 ← родительский кабинет (React)
│   └── App.jsx                ← уже есть прототип!
└── books/                     ← сюда складываются пакеты книжек
    └── grondheim_01/          ← первая книга
```

## Быстрый старт (Фаза 1)

```bash
# 1. Установить зависимости
pip install fastapi uvicorn

# 2. Запустить сервер
cd server
uvicorn main:app --reload --port 8000

# 3. Открыть плеер
# Открыть player/index.html в браузере
```
