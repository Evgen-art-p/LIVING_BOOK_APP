### 🔥 Задача №1 (Критическая): Реализовать `free_talk` через Прокси-Маяк

**Что нужно сделать в `index.html`:**

1. **Добавить функцию `askLLM(text, scene)`**:
   - Вызывается, когда локальный `matchIntent` не нашёл совпадений (после `SoftBoundary`, но до `fallback`).
   - Отправляет POST-запрос на `http://localhost:8001/api/free_talk` (создать новый эндпоинт в `main.py`).
   - Тело запроса:
     ```json
     {
       "child_text": "Почему Пиксель светится?",
       "scene_id": "branch_forest_scene",
       "chapter_id": "ch01",
       "child_name": "Женя",
       "session_id": "session_001"
     }
     ```
   - Таймаут: 5 секунд. Если сервер не отвечает → тихий fallback на локальную фразу *«Я тебя слышу, дай подумать секунду...»* (без шума в консоли).

2. **Добавить кэш LLM-ответов** (`llm_cache` в `localStorage` или `IndexedDB`):
   - Ключ: `hash(child_text + scene_id)`.
   - Время жизни: 7 дней.
   - При повторном вопросе ответ берётся из кэша — бесплатно и мгновенно.

3. **Обновить `onChildSpoke`**:
   ```javascript
   // После GlobalIntents и SoftBoundary
   const localReply = await Dialog.getReply(text, scene);
   if (localReply.text !== fallbackText) {
       // есть локальный intent
       speak(localReply.text, localReply.audio);
   } else {
       // нет локального — идём в LLM
       const llmReply = await askLLM(text, scene);
       if (llmReply) {
           speak(llmReply.text, null, llmReply.color);
           await Memory.saveUtterance(SESSION_ID, text + " [LLM]");
       } else {
           speak(fallbackText);
       }
   }
   ```

### 🔥 Задача №3 (Звук): Включить воспроизведение foley и ambient

**В `index.html`:**

1. **Инициализировать `Howler.js`** (добавить в `<head>`):
   ```html

   ```

2. **Создать `SoundManager`**:
   ```javascript
   const SoundManager = {
       currentMusic: null,
       currentFoley: [],
       
       playFoley(soundName, volume = 0.5, loop = false) {
           const sound = new Howl({
               src: [`audio/foley/${soundName}.mp3`],
               volume: volume,
               loop: loop,
               html5: true
           });
           sound.play();
           return sound;
       },
       
       playAmbient(musicDesc, volume = 0.3) {
           // временно: по описанию выбираем MP3 из библиотеки
           const musicMap = {
               "forest": "audio/ambient/forest_magic.mp3",
               "waterfall": "audio/ambient/waterfall_mystery.mp3"
           };
           const url = musicMap[musicDesc] || null;
           if (url && this.currentMusic) {
               this.currentMusic.stop();
           }
           if (url) {
               this.currentMusic = new Howl({ src: [url], loop: true, volume: volume });
               this.currentMusic.play();
           }
       },
       
       stopAll() {
           if (this.currentMusic) this.currentMusic.stop();
           this.currentFoley.forEach(s => s.stop());
           this.currentFoley = [];
       }
   };
   ```

3. **В `playScene(scene)`** после загрузки сцены:

       }
       if (scene.audio_layer.ambient) {
           SoundManager.playAmbient(scene.audio_layer.ambient, 0.25);
