# 🧠 ГЛУБОКИЙ АНАЛИЗ: Карта vs Реальность (ROADMAP → Факт)

## 1. СТРАТЕГИЧЕСКОЕ НЕСООТВЕТСТВИЕ: «Живая Книга» vs «Скриптованная Книга»

**ROADMAP (Фаза 2 & 3):**
> «Primary Channel — Звук», «Никакого "Голого" LLM», «Все запросы через конвейер агентов», «Интеграция API LLM для режима free_talk».

**Факт (A16 `book.json` + `ch01.json`):**
- `mode: "ask_choice"` — 100% скриптованный выбор.
- `free_talk` **отсутствует**.
- Ребёнок **не может** сказать ничего, кроме заранее заданных вариантов.

### 🔴 КРИТИЧЕСКИЙ ВЫВОД:
**Это не «Живая Книга» (интерактивная LLM-история), а «Ветвящийся аудио-квест» (Choose-Your-Own-Adventure).**

Это противоречит:
- **Методу Гиппенрейтер** (ребёнок должен **выражать чувства словами**, а не тыкать в кнопки — но кнопок нет, а STT есть, но он бесполезен при `ask_choice` без парсинга свободной речи).
- **LB14 Эхо Сенсор** (STT перезапускается, но его результаты игнорируются, кроме как для Emergency/SoftBoundary).
- **Всему смыслу PWA без текстовых полей** — зачем ребёнку микрофон, если он не может сказать: *«Мне страшно»*, *«Я хочу домой»*, *«Расскажи ещё раз»*? Только триггеры на `помогите` и `отстань`.

👉 **Риск:** Ребёнок быстро потеряет интерес. Он будет чувствовать, что его голос **не имеет значения**, кроме редких исключений. Это убивает эмпатию и персонализацию.

## 2. АРХИТЕКТУРНЫЙ РАЗРЫВ: Клиент (index.html) vs Сервер (main.py + ui.py)

**Что есть:**
- `index.html` — полностью автономный клиент (Zero Data). Он **не обращается** к `main.py:8001` для диалога. Только NightBeacon раз в сутки.
- `main.py` — сервер с **реальными LLM-агентами** (SET, Fabula Fein, Vera Dusha, Marka Fain). Но он используется **только** для генерации **новых книг** по запросу из родительского кабинета (`/api/studio/generate`).
- `ui.py` — студия для **человека-редактора**, а не для ребёнка.

### 🔴 КРИТИЧЕСКИЙ ВЫВОД:
**В продакшне (когда `DEV_MODE = false`):**
- Ребёнок общается **только с локальным keyword-матчером**.
- LLM (Gemini через OpenRouter) **вообще не вызывается**.
- «Конвейер агентов» (Этика → Промпт → Нарратив) **не работает для живого диалога**.

👉 **Разрыв между ROADMAP (Фаза 2) и реальностью:** Фаза 2 не начата в клиенте. LLM-агенты живут в `main.py`, но клиент про них не знает.

## 4. АНАЛИЗ КОНКРЕТНОГО ПАКЕТА ОТ A16 (Марка Файн)

### Что в пакете **хорошо**:
- `ethics.json` — проработан, запрещённые темы и фразы указаны.
- `characters/*.json` — есть `system_prompt`, `voice_id`, `catchphrase`.
- Структура сцен (`ch01.json`) логична, 3 уровня выбора, финалы разные.

### Что **не соответствует** ROADMAP и техническим возможностям:

| Элемент пакета | Проблема |
|----------------|-----------|
| `audio.foley` массив | В `index.html` нет кода для их воспроизведения. |
| `audio.music` текстовое описание | Должен быть путь к MP3 или параметры для генерации музыки. |
| `audio.spatial` | Не поддерживается клиентом. |
| `mode: "ask_choice"` | Нет `free_talk`, нет LLM. |
| `"tts_model": "elevenlabs"` | В клиенте используется только `Web Speech API`, не ElevenLabs. |
| `"llm": { "provider": "google", "model": "gemini-3.1-pro" }` | Клиент не вызывает LLM. |
| `after_speech: "ask_choice"` | После речи рассказчика — ждёт выбора. Но ребёнок может сказать **что угодно**, а не только `choice.label`. Это приведёт к fallback'у или игнору. |

👉 **Пакет A16 — это отличный **дизайн-документ**, но **не исполняемый код** для текущего клиента.

## 5. СЦЕНАРНЫЙ АНАЛИЗ: Что произойдёт, если ребёнок скажет…

| Фраза ребёнка | Ожидание (ROADMAP) | Реальность (код) |
|---------------|---------------------|------------------|
| *«Пойду в Лес Чудес»* | STT → keyword matching → выбор `choice_forest` | ✅ Сработает, если `keywords` содержат `лес` или `чудес`. |
| *«Мне страшно, я не хочу туда идти»* | Эмпатический ответ, направляющий вопрос. | ⚠️ `SoftBoundary` перехватит `не хочу` → ответ «дух Вредности». Это **не эмпатия**. |
| *«Расскажи ещё раз про карту»* | LLM генерирует пересказ. | ❌ Нет LLM → fallback: *«Я слышу тебя. Расскажи ещё.»* |
| *«Помогите, я заблудился»* | Emergency Stop → зовёт взрослого. | ✅ Сработает (ключевое слово `помогите`). |
| *«Почему Пиксель светится?»* | LLM объясняет lore. | ❌ Fallback. |
